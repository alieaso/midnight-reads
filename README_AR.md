# Midnight Reads — النسخة الثانية (واجهة محسّنة)

## ما الموجود في هذه النسخة؟
- واجهة متجر داكنة ومتجاوبة باللغة الإنجليزية.
- أساسيات SEO داخل الصفحة: عنوان ووصف، canonical placeholder، بيانات منظمة أولية، وملفات `robots.txt` و`sitemap.xml`.
- صفحة تجريبية لشكل لوحة المالك تتضمن أقسام الكتب والإعلانات وSEO والطلبات والإعدادات.
- أماكن إعلانية توضيحية، وليست أكواد Adsterra أو AADS حقيقية.

## مهم جدًا
هذه **واجهة أولية وليست متجرًا جاهزًا للبيع**:
- صفحة `admin-demo.html` ليست محمية بتسجيل دخول، ولا ينبغي اعتبارها لوحة آمنة.
- لا توجد قاعدة بيانات أو نظام مستخدمين أو دفع أو تحقق آلي من USDT.
- لا يوجد تخزين خاص لملفات الكتب أو روابط تنزيل مؤقتة.
- الكتب والأسعار والأوصاف المعروضة أمثلة تجريبية؛ استبدلها بمحتوى حقيقي قبل الإطلاق.
- لا تضف أسرارًا أو مفاتيح API أو معلومات محفظة خاصة إلى ملفات الموقع أو مستودع عام.

## قبل النشر
1. استبدل `https://YOUR-DOMAIN-OR-SITE-URL/` بعنوان الموقع النهائي في `index.html` و`robots.txt` و`sitemap.xml`.
2. حدّث الروابط في خريطة الموقع لتشمل الصفحات العامة الفعلية فقط.
3. اختبر سياسات الاستضافة وشبكات الإعلانات بخصوص نوع المحتوى المنشور.
4. أضف مصادقة إدارية من جهة الخادم وقاعدة بيانات قبل استخدام لوحة المالك فعليًا.
5. نفّذ الدفع والتحقق من المعاملات وتسليم الملفات من جهة الخادم فقط.
6. أنشئ صفحات الخصوصية والشروط والاتصال بمحتوى صحيح قبل جمع أي بيانات.

## ملفات المشروع
- `index.html` — واجهة المتجر.
- `styles.css` — التصميم.
- `script.js` — تفاعلات بسيطة.
- `admin-demo.html` — نموذج مرئي للوحة التحكم فقط.
- `robots.txt` و`sitemap.xml` — قوالب SEO تحتاج إلى تحديث العنوان النهائي.
